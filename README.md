# VCL Language Support

Syntax highlighting and language support for Varnish Configuration Language (VCL) files.

## Features

- Syntax highlighting for VCL 4.0+ files
- Code folding and bracket matching
- Comment toggling support
- Custom color theme optimized for VCL

## Installation

Install from the VS Code Marketplace or Cursor Extensions.

## Usage

Open any `.vcl` file and enjoy syntax highlighting!
